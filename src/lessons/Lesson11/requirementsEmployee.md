Employee project

Требования: 
● Сверстать страницу по дизайну: ссылка на дизайн https://www.figma.com/design/QbSmbuBHbK6PBgEkLSOXBv/User-Form?node-id=0-1&t=PwBAgLO137mBnxVZ-0
● Название формы Create Employee располагается по центру страницы
● Когда загружается приложение, видна только форма (сслева на странице)
● Форма содержит следующие поля: Name (обязательное поле), Surname (обязательное поле), Age (обязательное поле), Job Position (необязательное поле)
● Когда пользователь вводит данные во все инпуты и нажимает на кнопку "Создать", появляется карточка справа от формы с данными пользователя, которые он ввел в форме (см. дизайн https://www.figma.com/design/QbSmbuBHbK6PBgEkLSOXBv/User-Form?node-id=0-1&t=PwBAgLO137mBnxVZ-0) 
● Если данные пользователя не прошли валидацию, то submit не должен происходить

1. "Name": - компонент Input; - обязательное поле; - тип данных: string; - минимальное количество символов - 2; - максимальное количество символов - 50
2. "Surname": - компонент Input; - обязательное поле; - тип данных: string; - максимальное количество символов - 15; 
3. "Age": - компонент Input; - обязательное поле; - тип данных: number; - минимальное значение - 18; - максимальное значение - 80;
4. "Job Position": - компонент Input; - необязательное поле; - тип данных: string; - максимальное количество символов - 30;

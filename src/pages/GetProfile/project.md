Требования:
Добавьте в приложение 2 страницы: "Get Profile" и "Profile".
2. На странице "Get Profile" должна находиться кнопка “GET USER PROFILE”. 
При клике на кнопку должен происходить запрос на получение данных пользователя URL “https://randomuser.me/api/”. 
При успешном запросе на странице появляется сообщение “Data successfully retrieved. Go to the profile page.”. 
Во время запроса должен быть показан спиннер. 
В случае ошибки необходимо вывести сообщение об ошибке на странице
3. На странице “Profile” должна быть показана карточка пользователя, при успешном получении данных, в которой должна быть следующая информация 
Имя и Фамилия
Картинка
Пол
Электронная почта
Страна 
Телефон
